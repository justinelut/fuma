# `@fuma/brand`

Framework- and runtime-neutral public identity metadata for Fuma applications.

The package currently exports `FUMA_PUBLIC_IDENTITY` and its derived `FumaPublicIdentity` type. Values are limited to facts ratified in `docs/reference/fuma-configuration.md` and `apps/studio/server/fuma/config.ts`: the Fuma name, reserved product and marketing hosts, deferred marketing status, and Kenya launch defaults.

This package owns no routes, sessions, behavior, business or commercial truth, schemas, persistence, authentication, UI components, or workspace dependencies. No logo or wordmark is included because no Fuma artwork is ratified by those sources.
