## Configure environment variables manually

Copy `apps/web/client/.env.example` to `apps/web/client/.env` and configure at least:

```properties
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/onlook
BETTER_AUTH_SECRET=<unique-random-secret-at-least-32-characters>
BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_SITE_URL=http://localhost:3000
OBJECT_STORAGE_ENDPOINT=http://127.0.0.1:9000
OBJECT_STORAGE_REGION=us-east-1
OBJECT_STORAGE_ACCESS_KEY_ID=minioadmin
OBJECT_STORAGE_SECRET_ACCESS_KEY=minioadmin
OBJECT_STORAGE_BUCKET=onlook
REDIS_URL=redis://127.0.0.1:6379
OPENROUTER_API_KEY=<openrouter-key>
CSB_API_KEY=<codesandbox-key>
```

Create `packages/db/.env` with the same `DATABASE_URL`:

```properties
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/onlook
```

Then run `bun db:migrate` and optionally `bun db:seed`.
