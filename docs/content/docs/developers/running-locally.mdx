# Development Setup

## Prerequisites

- Bun
- Docker with Compose
- Node.js 20.16+

## Install and configure

```bash
git clone https://github.com/onlook-dev/onlook.git
cd onlook
bun install
bun run setup:env
```

The setup command writes `DATABASE_URL`, Better Auth, MinIO, Redis, CodeSandbox, and OpenRouter values. See `.env.example` for optional providers.

## Start data services

```bash
docker compose up -d postgres redis minio
bun db:migrate
bun db:seed
```

Drizzle applies the complete PostgreSQL schema, including Better Auth tables. The seed creates a Better Auth credential user and matching domain/project records.

## Run the application

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000). The MinIO console is available at [http://localhost:9001](http://localhost:9001).

When schema changes are supplied by maintainers, rerun `bun db:migrate`. Do not run `db:gen` unless you are maintaining the canonical migration history.
