# External Services

## Data and identity

1. **PostgreSQL 17+** stores Better Auth and application domain tables. Drizzle owns schema changes through `bun db:migrate`.
2. **MinIO or compatible S3 storage** stores project previews and media. Keep credentials server-side.
3. **Redis** is the coordination endpoint for shared-state features that need cross-replica fan-out or locking.
4. **Better Auth** runs inside the web application; it does not require a separate auth service.

These services can run in Docker Compose, K3s, or managed equivalents. Use private networking and TLS outside a trusted cluster.

## Sandbox providers

CodeSandbox currently hosts editable project sandboxes. Configure `CSB_API_KEY`. A local provider may be added through the code-provider abstraction.

## AI providers

OpenRouter is the default chat provider. Other AI SDK providers can be configured in `packages/ai` and through the optional environment variables in `apps/web/client/.env.example`.
